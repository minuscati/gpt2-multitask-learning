# Attribution

This repository is a portfolio-oriented derivative of the course starter repository [`cfifty/public_cs224n_gpt`](https://github.com/cfifty/public_cs224n_gpt), which was provided for an educational GPT-2 implementation project.

The starter repository states that it was adapted from the Stanford CS224N MinBERT project and includes code adapted from Hugging Face Transformers. Its Apache License 2.0 is preserved in this repository.

Course-project contributions include completing and modifying core GPT-2 components, implementing and testing the optimizer, extending the classification and hyperparameter-search workflows, and conducting fine-tuning, regularization and generation experiments.

This was completed as a team course project. The repository does not claim authorship of the starter framework or third-party components.
